# 💳 Credit Card Fraud Detection System

🚀 A Machine Learning project to detect fraudulent credit card transactions with an interactive **Streamlit Web App**.

This system analyzes transaction data and predicts whether a transaction is **fraudulent or legitimate** using a trained ML model.

---

## 📌 Features

- 🔍 Real-time fraud detection
- 🤖 Machine Learning model integration
- 📊 Data preprocessing & feature scaling
- 🖥️ Interactive and clean Streamlit UI
- ⚡ Fast and easy predictions

---

## 🛠️ Technologies Used

- Python 🐍
- Scikit-learn
- Pandas & NumPy
- Streamlit
- Joblib / Pickle
